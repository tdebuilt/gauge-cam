# Mockups

Design proposals for the device interface and the install page (`docs/plan-refonte-ux.md`).
Self-contained HTML pages, offline; open `propositions/index.html` (four directions) or
`propositions/a-plus.html` (first set-up path). Rebuild with `python3 propositions/build.py` and
`python3 propositions/build_aplus.py`.

- Data shown is fictional; the dial photo is a real Afriso gauge.
- Fonts embedded in `propositions/fonts.css`: Inter, Manrope and IBM Plex Mono, SIL Open Font License 1.1.
