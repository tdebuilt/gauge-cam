Gauge Cam

Lecture d'une jauge à aiguille (niveau de cuve à mazout) par un ESP32-CAM, publiée dans Home Assistant par MQTT.

Reads a needle gauge (oil tank level) with an ESP32-CAM and publishes it to Home Assistant over MQTT.

Navigateur non pris en charge : utilise Chrome ou Edge sur ordinateur. Browser not supported: use Chrome or Edge on a computer. Cette page doit être ouverte en HTTPS. This page must be opened over HTTPS.

Installation

  1. Branche l'ESP32-CAM sur sa carte USB ESP32-CAM-MB, puis sur l'ordinateur.
  2. Clique sur le bouton ci-dessus, choisis le port série, puis Installer. Si la connexion échoue, maintiens le bouton IO0 de la carte MB en appuyant sur RST, puis relâche-le.
  3. Après l'installation, la page propose de régler le Wi-Fi : choisis le réseau (celui des objets connectés) et saisis son mot de passe.
  4. Ouvre ensuite l'appareil (lien proposé, ou http://gauge-cam-xxxxxx.local/) et règle le cadran, la cuve et MQTT.

Tant que le Wi-Fi n'a jamais fonctionné, l'appareil ouvre aussi un point d'accès gauge-cam-xxxxxx : connecte-toi dessus, la page de réglage s'ouvre sur http://192.168.4.1/.

Changer de Wi-Fi plus tard : rebranche l'appareil en USB, clique sur le bouton ci-dessus, puis l'option de changement de Wi-Fi. Ou donne un mot de passe au point d'accès de secours (Réglages → Réseau et MQTT) : il s'ouvrira après 30 s sans Wi-Fi.

Mise à jour d'un appareil déjà installé : entité Firmware dans Home Assistant, ou Réglages → Système de son interface ; à la main, avec le fichier gauge-cam.bin de la dernière version.

Installation

  1. Plug the ESP32-CAM into its ESP32-CAM-MB USB board, then into the computer.
  2. Click the button above, pick the serial port, then Install. If it cannot connect, hold the IO0 button of the MB board while pressing RST, then release it.
  3. After the installation the page offers to set up Wi-Fi: pick the network and type its password.
  4. Then open the device (offered link, or http://gauge-cam-xxxxxx.local/) and set up the dial, the tank and MQTT.

As long as Wi-Fi has never worked, the device also opens a gauge-cam-xxxxxx access point: join it and the set-up page opens on http://192.168.4.1/.

To change Wi-Fi later: plug the device in over USB, click the button above, then Change Wi-Fi. Or give the fallback access point a password (Settings → Network and MQTT): it will open after 30 s without Wi-Fi.

To update an installed device: the Firmware entity in Home Assistant, or Settings → System in its interface; by hand, with the gauge-cam.bin file of the latest release.
